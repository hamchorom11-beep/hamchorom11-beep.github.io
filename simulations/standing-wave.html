정상파의 형성

서로 반대 방향으로 진행하는 진동수와 진폭이 같은 두 파동이 중첩되면 공간에서 이동하지 않는 것처럼 보이는 정상파가 형성됩니다.

마디(node) : 항상 변위가 0인 위치
배(antinode) : 진폭이 가장 큰 위치

인접한 두 마디 또는 두 배 사이의 거리는

λ / 2

이고, 마디와 가장 가까운 배 사이의 거리는

λ / 4

현과 양쪽 열린 관

양 끝이 고정된 현에서는 양 끝이 마디입니다. 양쪽 열린 관에서 공기 입자의 변위를 기준으로 보면 양 끝이 배가 됩니다. 두 경우 모두 길이 L에는 반파장의 정수배가 들어갑니다.

L = nλ/2
fₙ = nv/(2L)

한쪽 끝이 닫힌 관

닫힌 끝에서는 공기 입자가 움직일 수 없으므로 변위의 마디가 형성되고, 열린 끝에서는 공기 입자의 움직임이 가장 커 변위의 배가 형성됩니다.

L = (2n − 1)λ/4
fₙ = (2n − 1)v/(4L)
한쪽 끝이 닫힌 관에서는 1배, 3배, 5배, 7배 … 진동만 나타납니다. 즉 기본 진동수의 홀수배만 허용됩니다.
관에서 이 시뮬레이션은 공기 입자의 변위를 표시합니다. 따라서 열린 끝은 변위의 배, 닫힌 끝은 변위의 마디입니다. 압력 정상파로 표현하면 마디와 배의 위치가 서로 반대가 됩니다.

탐구 활동

  1. 현의 기본 진동을 관찰하고 양 끝이 마디인지 확인하세요.
  2. 현에서 n을 1, 2, 3, 4로 바꾸어 마디와 배의 개수가 어떻게 변하는지 확인하세요.
  3. 현의 길이는 그대로 두고 n을 2배로 하면 파장과 진동수는 각각 어떻게 변하는지 확인하세요.
  4. 양쪽 열린 관으로 바꾸어 양 끝이 배가 되는지 확인하세요.
  5. 현과 양쪽 열린 관은 끝 조건이 서로 다른데도 왜 파장과 고유진동수 식은 같은 형태인지 설명하세요.
  6. 한쪽 끝이 닫힌 관의 기본 진동에서 닫힌 끝과 열린 끝의 마디·배를 확인하세요.
  7. 한쪽 닫힌 관에서 2번째 모드를 선택하세요. 화면에는 몇 배 진동이 표시되는지 확인하세요.
  8. 한쪽 닫힌 관의 모드를 차례로 바꾸며 1, 3, 5, 7배 진동만 나타나는 이유를 경계 조건을 이용하여 설명하세요.
  9. 길이 L을 2배로 증가시키면 기본 진동수가 어떻게 변하는지 확인하세요.
  10. 파동의 속력 v를 증가시키면 파장은 같은 모드에서 어떻게 되고, 진동수는 어떻게 변하는지 확인하세요.
