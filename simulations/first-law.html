열역학 제1법칙

Q = ΔU + W
이 시뮬레이션에서 W는 기체가 외부에 한 일입니다.
팽창하여 기체가 외부에 일을 하면 W > 0, 압축되어 기체가 외부로부터 일을 받으면 W < 0입니다.

네 가지 열역학 과정

과정 일정한 조건 ΔU W Q
등온 T 일정 0 ≠ 0 Q = W
등압 P 일정 ≠ 0 PΔV Q = ΔU + W
등적 V 일정 ≠ 0 0 Q = ΔU
단열 Q = 0 ≠ 0 ≠ 0 ΔU = −W
Q = ΔU + W

여기서 W는 기체가 외부에 한 일 입니다.

기체가 팽창하면 외부에 일을 하므로 W > 0입니다. 반대로 기체가 압축되면 외부로부터 일을 받으므로 기체가 외부에 한 일은 W < 0입니다.
P-V 그래프에서 과정 곡선 아래의 넓이는 기체가 외부에 한 일 W와 대응합니다. 팽창 과정에서는 W가 양수, 압축 과정에서는 W가 음수입니다.

탐구 활동

  1. 등온 팽창을 선택하세요. 온도가 일정한 상태에서 기체가 외부에 일을 하는데도 내부에너지가 변하지 않는 이유를 Q = ΔU + W를 이용하여 설명하세요.
  2. 등압 팽창을 진행하면서 P-V 그래프 아래의 음영 넓이가 증가하는 모습을 관찰하세요. 이 넓이는 어떤 물리량에 해당하나요?
  3. 등적 과정을 선택하세요. P-V 그래프의 과정이 수직선으로 나타나고 W = 0이 되는 이유를 부피 변화와 연결하여 설명하세요.
  4. 같은 최종 부피까지 등온 팽창과 단열 팽창을 진행하세요. 단열 과정에서 압력과 온도가 더 크게 감소하는 이유를 설명하세요.
  5. 단열 팽창에서 Q = 0, W > 0, ΔU < 0 이 되는 것을 확인하고 Q = ΔU + W 에 대입하여 관계가 성립하는지 확인하세요.
  6. 압축 과정을 선택하세요. 기체가 외부로부터 일을 받을 때 W가 음수가 되는 것을 확인하고 팽창 과정과 비교하세요.
