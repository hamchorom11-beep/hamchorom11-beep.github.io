🌡️ 열역학 제1법칙 시뮬레이션

이상기체의 등온, 등압, 등적, 단열 과정을 직접 변화시키며 압력-부피 관계와 열, 일, 내부에너지 변화 사이의 관계를 탐구합니다.

탐구 질문 : 열역학 과정에 따라 기체가 받은 열 Q, 기체가 한 일 W, 내부에너지 변화 ΔU의 크기와 부호는 어떻게 달라질까?

열역학 제1법칙

ΔU = Q − W

네 가지 열역학 과정

과정 일정한 물리량 ΔU W Q
등온 T 0 ≠ 0 Q = W
등압 P ≠ 0 PΔV ΔU + W
등적 V ≠ 0 0 Q = ΔU
단열 Q = 0 ≠ 0 ≠ 0 0
ΔU = Q − W

이 시뮬레이션에서는 기체가 외부에 한 일을 양(+)의 일로 정의합니다.

팽창하면 일반적으로 기체가 외부에 일을 하므로 W > 0이고, 압축하면 외부가 기체에 일을 하므로 기체가 한 일은 W < 0입니다.
내부에너지는 상태량이므로 처음과 마지막 상태에 의해 결정되지만, 열과 일은 어떤 과정을 거쳤는지에 따라 달라집니다.

탐구 활동

  1. 등온 팽창을 선택하고 부피를 증가시키세요. 온도와 내부에너지 변화가 어떻게 되는지 확인하고, 기체가 일을 하면서도 온도가 일정하게 유지되는 이유를 설명해 보세요.
  2. 등적 과정을 선택하여 온도를 증가시키세요. P-V 그래프에서 경로는 어떤 모양이며, 기체가 한 일이 0인 이유를 설명해 보세요.
  3. 등압 팽창에서 기체가 받은 열에너지와 내부에너지 증가량을 비교하세요. 두 값의 차이는 어디에 사용되나요?
  4. 등온 팽창과 단열 팽창을 같은 부피 변화로 비교하세요. 어느 과정에서 압력이 더 빠르게 감소하나요?
  5. 단열 팽창에서 Q = 0인데도 온도와 내부에너지가 감소하는 이유를 열역학 제1법칙을 이용해 설명하세요.
  6. 팽창과 압축을 서로 바꾸어 Q, W, ΔU의 부호가 어떻게 달라지는지 비교하세요.
